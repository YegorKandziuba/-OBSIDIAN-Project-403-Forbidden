2. **Решения фиксируются в журналах**, не в тексте заметок:

   - Бордо: [[CLAUDE - Бордо - журнал решений]];

4. **Сцены** строить по шаблону `20 Кампании/Сумеречная Сфера Риверкель/Сессии/Сезон 2/Сессия 1/Сцена - Шаблон.md`: суть → экспозиция → социальное → столкновение → последствия.
