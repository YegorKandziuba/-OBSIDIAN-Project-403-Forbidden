# Орден Восьмого Порядка

## Основные сведения
- **Название**: Орден Восьмого Порядка
- **Тип организации**: Тайная инквизиция Церкви Великой Семёрки
- **Статус**: Официально не признан
- **Основная цель**: Борьба с тайными угрозами
- **Девиз**: "Свет семи ведёт, восьмой скрывает тень"
- **Примерная численность**: Несколько десятков агентов
- **Расположение штаба**: Множественные тайные ячейки (одна известная - подвал монастыря в графстве Риверкель)

## Историческая справка
### Основание
- Основатель: Ахт
- Период основания: Несколько десятилетий после появления Великой Семёрки
- Причина создания: Необходимость тактической подготовки для борьбы с магическими и демоническими угрозами

### Эволюция организации
1. Первоначальная форма: Группа религиозных фанатиков
2. Промежуточный этап: Развитие разведывательной и следственной деятельности
3. Современное состояние: Автономная структура, независимая от официальной инквизиции

## Организационная структура
### Иерархия
1. Верховный инквизитор (личность засекречена)
2. Архивариус
3. Теневые клинки
4. Вестники правды
5. Оперативные ячейки
6. Сеть информаторов

### Принципы работы
- Автономность ячеек (3-5 человек)
- Строгая секретность
- Независимость действий
- Гибкая структура командования

## Идеология и методология
### Основные принципы
1. Абсолютная секретность
2. Приоритет результата над моралью
3. Контроль информации
4. Прагматичный подход к доктрине

### Тактические методы
1. Разведывательная деятельность
2. Ликвидация угроз
3. Тайные операции
4. Контроль артефактов
5. Охота на Мёртвых Апостолов

## Опознавательные знаки
### Символика
- Основной символ: Модифицированная эмблема Великой Семёрки
- Восьмой луч: Скрытый элемент среди семи основных

### Система сигналов
#### Приветствия
- Формальное: Поклон с жестом "восьмёрки"
- Скрытое: Поглаживание безымянного пальца

#### Тревожные сигналы
- Поднятый мизинец: Требуется внимание
- Постукивание по левой руке: Близкая опасность
- Касание уха: Подтверждение получения информации
