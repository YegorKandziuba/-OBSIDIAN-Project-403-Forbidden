# FVTT сеттинга — импорт в Foundry (система PF2e)

Файлы для Foundry VTT, которые относятся к миру, а не к одной кампании. Формат — документы системы **Pathfinder Second Edition** (схема ремастера), UTF-8 без BOM. Один файл — один документ. Файлы «Сломанной бусины» лежат отдельно, в его папке `FVTT/`.

## Как импортировать
**Актёры** (`Actors/`): во вкладке «Актёры» создайте пустого актёра типа **NPC** → правый клик по нему → **Import Data** → выберите файл. Имя и всё содержимое заменятся.

## Что нужно доделать руками
- **Предметы снаряжения** (кандалы, фонарь, отмычки, доспехи) в актёров не вложены — список в «Публичных заметках» актёра. Перетащите из компендиума, если нужно.
- **Правил автоматизации нет**: бонусы «Плечом к плечу», «Строй, лунатики!», «Знает цель» и т. п. применяйте вручную.

## Проверка
Файлы проверены на корректный JSON и отсутствие BOM, но **не проверены в самом Foundry**. Если при импорте что-то не так, напишите, что именно и какая версия системы, — поправлю.

## Божество «Творец» *(2026-10-13, черновик)*
`Items/deity-tvorec.json` — Творец как божество PF2e: оба источника (исцеление и вред), освящение «может быть святым», атрибуты Мудрость или Харизма, навык Общество, оружие — кинжал, домены (Солнце, Творение, Душа, Истина; альтернативные — Исцеление, Защита, Долг, Рвение, Бдение), заклинания жреца (1 — *святилище*, 2 — *очищение от недуга*, 3 — *святой свет*, 5 — *изгнание*), заповеди и анафема в описании.
- **Импорт:** откройте в мире существующий предмет «Творец» (тип «Божество») → правый клик → **Import Data** → этот файл. Если создаёте новый — сначала пустой предмет типа «Божество».
- **Персонажи:** у жреца в листе лежит **копия** старого пустого «Творца». После импорта перетащите обновлённое божество на лист жреца (и Генри), заменив старое.

## Формат файлов (исправлено 2026-10-11)
Первая версия файлов не импортировалась: система PF2e **молча отбрасывает** файл при Import Data, если в `system` нет поля `_migration`. Теперь все файлы приведены к формату экспорта из Foundry (образец мастера — Foundry 13.351, PF2e 7.10.1):
- в `system` у каждого документа и у каждого вложенного предмета есть `"_migration": { "version": 0.955, "previous": null }`;
- у документов есть `folder`, `effects`, `flags`, `ownership`, `_stats`; у вложенных предметов и страниц журнала — свои `_id`;
- у актёров есть `prototypeToken` с именем (враги — враждебные, брат Тибо — дружественный).

> [!warning] Версия системы
> `0.955` — версия схемы PF2e 7.10.x. Если система в мире **старее** (например, 7.7.x — схема 0.953), импорт выдаст ошибку «версия слишком новая». Тогда замените во всех файлах `0.955` на версию вашего мира.
