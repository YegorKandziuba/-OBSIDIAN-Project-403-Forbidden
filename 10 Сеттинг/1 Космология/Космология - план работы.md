# Космология — план работы

> [!info] Зачем этот файл
> Пошаговый план описания космологии мира *Project 403: Forbidden*. Идём сверху вниз: сначала устройство мироздания, потом то, что в нём живёт, и только в конце — религии, которые люди выстроили поверх. Вера описывается **после** космологии.
> Главный источник — **рукописная тетрадь мастера**. Заметки в хранилище — вторичный источник: если они противоречат тетради, решает мастер.

## Как работаем
1. **Шаг за шагом.** Один шаг — одна тема — одна заметка в этой папке. Пока шаг не закрыт, следующий не начинаем, разве что по прямой просьбе.
2. **Порядок внутри шага:**
	1. Мастер даёт материал: страницы тетради, мысли, ответы.
	2. Claude сводит его с тем, что уже есть в хранилище, и выписывает противоречия.
	3. По каждому открытому вопросу Claude даёт 3–6 вариантов с одной рекомендацией.
	4. Решает мастер.
	5. Claude пишет заметку. Свои придумки помечает *(предложение)*.
	6. Решение заносится в «Журнал решений» внизу этого файла.
3. **В каждой заметке есть раздел «Кто что знает»**: обыватели, Церковь, Ложа и маги, Волшебники, мастер. Сеттинг держится на тайне, поэтому для каждого факта важно, кому он известен.
4. **Тайна мастера** оформляется отдельным выноской `> [!danger] Только для мастера`.
5. **Термины** сразу заносятся в глоссарий (шаг 1), чтобы одно и то же не называлось тремя разными словами.
