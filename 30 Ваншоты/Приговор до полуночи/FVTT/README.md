# FVTT — импорт в Foundry (система PF2e)

Все файлы — отдельные документы Foundry в формате системы **Pathfinder Second Edition** (схема ремастера, v6+). Один файл = один документ.

## Как импортировать
1. **Актёры** (`Actors/`, `Hazards/`): во вкладке «Актёры» создайте пустого актёра нужного типа — **NPC** для файлов `npc-…`, **Опасность (Hazard)** для `hazard-…`. Правый клик по нему в боковой панели → **Import Data** → выберите файл. Имя и всё содержимое заменятся.
2. **Предметы** (`Items/`): во вкладке «Предметы» создайте пустой предмет того же типа — **Черта (Feat)** для `feat-…`, **Эффект** для `effect-…`, **Оружие** для `weapon-…`, **Снаряжение** для `equipment-…`. Правый клик → **Import Data**.
3. **Журнал** (`Journal/`): создайте пустую запись журнала → правый клик → **Import Data** → `journal-razdatki.json`. Внутри шесть страниц: раздатки 1–5 и сводка фактов для мастера.

## Что нужно доделать руками
- **Заклинания.** У «Подарка Судьбы» и Одель-Жрицы созданы записи заклинателя, но сами заклинания не вложены. Список — в описании записи: перетащите их из компендиума.
- **Яды и эликсиры Одель** перечислены в заметках актёра. Добавьте из компендиума, если хотите тратить их по правилам.
- **Шаблон Weak** для Палимпсеста при 3 игроках — кнопкой «Weak» на листе NPC, отдельного файла нет.
- **Тень «Подарка Судьбы».** Когда оболочка сброшена, выставьте тени текущие ОЗ = половина ОЗ оболочки.
- **Мизерикорд Сесиль и белая маска** опираются на *bloodletting kukri* и *hat of disguise*. Их активации, уровень и цену перенесите из компендиума.
- **Черты архетипа.** Лор Ордена и запись заклинателя для «Молитвы Мизерикорда» добавьте персонажу вручную. «Удар милосердия» — +1d6 точного урона вручную.

## Автоматизация
Правила (rule elements) есть только там, где я уверен в синтаксисе:
- «Подлый укол» у Одель — +2d6 урона ядом по застигнутым врасплох.
- «Последнее отпущение» (эффект) — быстрое лечение 3.
- Посвящение Экзекутора — мизерикорд считается воинским оружием.

## Проверка
Файлы проверены на корректный JSON, но **не проверены в самом Foundry**: у меня нет доступа к вашей версии системы. Если при импорте что-то не так — поле не отображается, трейт пропал, правило выдаёт предупреждение, — напишите, что именно и какая версия PF2e, и я поправлю.
