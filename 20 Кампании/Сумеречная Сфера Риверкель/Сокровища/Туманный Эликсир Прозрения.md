
## Компоненты
- **Туманный Шепот** (Туманный Лист) - серовато-белые листья с перламутровым отливом
  - Собирается на рассвете в туманные дни
  - Усиливает восприятие эфирного плана
  - При неправильном использовании вызывает помутнение зрения
  - Имеет свойство рассеивать иллюзии

- **Теневой Корень** - черно-фиолетовый корень
  - Усиливает связь с потусторонним
  - Ядовит при прямом контакте
  - Требует защитных перчаток при работе

- **Память Предков** (Седая Трава) - серые стебли с белыми прожилками
  - Помогает в общении с духами
  - Вызывает видения прошлого
  - Опасна при передозировке

## Приготовление смеси
1. Измельчить 3 листа Туманного Листа (7 оборотов по часовой стрелке)
2. Добавить щепотку измельченного Теневого Корня
3. Всыпать 3 измельченных стебля Памяти Предков
4. Смешать против часовой стрелки 13 раз
5. Дать настояться в серебряной чаше 3 минуты

## Свойства готовой смеси
- Создает фиолетовый дым при использовании
- Имеет перламутровый оттенок
- Пахнет утренней росой и старыми книгами

## Игромеханические эффекты (длительность 10 минут):
- Позволяет видеть невидимых существ и распознавать иллюзии (как заклинание See Invisibility)
- Даёт возможность общаться с духами
- Показывает остаточные образы прошлого в местах сильных эмоциональных событий
- Даёт бонус +2 к проверкам Оккультизма при исследовании призраков и духов

## Побочные эффекты
- При провале спасброска Воли КД 15: головокружение (-1 к атакам и проверкам навыков) и урон ядом 1d4.
- При критическом провале: временная слепота на 1d4 раунда и урон ядом 2d4
- Нельзя использовать чаще раза в день

## Применение в игре
- Разведка населённых призраками мест
- Поиск скрытых существ
- Расследование старых преступлений
- Общение с духами для получения информации

## Стоимость компонентов
- 5 ЗМ за дозу
- Требуется успешная проверка Ремесло КД 20 для создания
- Время создания: 1 час
